# GS Coffee — Sistema Web para Cafeteria

## Sobre o projeto

O GS Coffee é um sistema web desenvolvido para uma cafeteria, com funcionalidades voltadas aos clientes e à administração do negócio.

A aplicação permite que os clientes consultem o cardápio, realizem pedidos e acompanhem suas compras. Também conta com uma área administrativa para gerenciar produtos, categorias, pedidos e outras informações da cafeteria.

O projeto foi desenvolvido em equipe como parte de uma atividade acadêmica do SENAC, envolvendo desenvolvimento front-end, back-end e banco de dados.

## Funcionalidades

### Área do cliente

- Cadastro e login de usuários
- Visualização do cardápio
- Carrinho de compras
- Finalização de pedidos
- Acompanhamento de pedidos
- Cadastro e gerenciamento de endereços
- Avaliações de pedidos
- Recuperação de senha
- Acesso ao perfil do usuário

### Área administrativa

- Login administrativo
- Gerenciamento de produtos
- Gerenciamento de categorias
- Gerenciamento de pedidos
- Gerenciamento de avaliações
- Configurações do site
- Gerenciamento de contatos e endereços

## Arquitetura da aplicação

A aplicação é composta por três componentes principais:

- **Front-end:** desenvolvido com HTML, CSS e JavaScript, disponibiliza a interface para os clientes e a área administrativa do sistema.
- **Back-end:** desenvolvido com Node.js e Express, responsável pelo processamento das requisições, pelas regras de negócio e pela comunicação com o banco de dados.
- **Banco de dados:** MySQL, utilizado para armazenar e gerenciar as informações da aplicação.

O front-end está publicado no GitHub Pages, enquanto o back-end está hospedado separadamente. Os dois componentes trabalham integrados para disponibilizar as funcionalidades do sistema.
