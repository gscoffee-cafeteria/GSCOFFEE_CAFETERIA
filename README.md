# ☕ GS Coffee Cafeteria

Sistema web desenvolvido para uma cafeteria, com funcionalidades para clientes e administração.

## 👩‍💻 Desenvolvido por

- Iara Silva
- Camila Guimarães

## 🚀 Funcionalidades

### Cliente
- Cadastro e login de usuários
- Visualização do cardápio
- Carrinho de compras
- Finalização de pedidos
- Acompanhamento de pedidos
- Cadastro de endereços
- Avaliações de pedidos
- Recuperação de senha

### Administração
- Login administrativo
- Gerenciamento de produtos
- Gerenciamento de categorias
- Gerenciamento de pedidos
- Gerenciamento de avaliações
- Configurações do site
- Gerenciamento de contatos e endereços

## 🛠️ Tecnologias utilizadas

### Front-end
- HTML5
- CSS3
- JavaScript
- Bootstrap Icons

### Back-end
- Node.js
- Express
- MySQL
- JWT
- bcrypt
- Nodemailer
